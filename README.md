# DataVista

### Diagnosing Multimodal LLMs on Data Video Understanding

**Dynamic charts · Temporal reasoning · Data narratives**

## Overview

DataVista evaluates how well multimodal large language models understand data videos—stories told through charts, animation, and narration. It examines whether models can read chart data, connect evidence across time, and understand how visual evidence supports a narrative.

| Real-world videos | Evaluation questions | Topic domains | Question types |
|:---:|:---:|:---:|:---:|
| **961** | **6,775** | **5** | **10** |

## What does DataVista evaluate?

| Level | Capability | Focus |
|:---|:---|:---|
| **L1** | **Data Perception** | Read data values and recognize chart elements. |
| **L2** | **Temporal Reasoning** | Connect evidence across charts and time points. |
| **L3** | **Narrative Understanding** | Understand narrative structure, visual design, and communication quality. |

The benchmark spans **Economy, Society, Science, Politics, and Culture**, with both single-answer and multiple-select questions.
